# Linux & Steam Deck
![](banner_2)
**Experimental.** The server, the database and the launcher run natively on Linux. The game runs through Proton, which the launcher downloads and keeps in its own folder. Nothing is installed system-wide and nothing needs sudo.

## What you need
- A 64-bit Linux from 2022 or newer (SteamOS 3.5+, Bazzite, Fedora 37+, Ubuntu 22.04+, Arch, Mint 21+).
- About 25 GB free.
- Your updated **SquareEnix** game folder (copied from a Windows PC, or the game installed on Linux).

## Install
1. Download **XI-Forever-Offline-Linux.tar.gz** and extract it (Steam Deck: in Desktop Mode).
2. Run **XI-Forever-Offline** in the folder.
3. The setup asks for the game folder, your world and an account, then downloads what it needs.

## Steam Deck
Launcher: **SYSTEM > Linux > Add to Steam and the menu**, then start it from your library in Game Mode.
